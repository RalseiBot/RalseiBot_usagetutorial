Ralsei Bot使用教程

1:如何让Bot回答你 @bot 发送/均可触发bot回复

2:漂流瓶功能

2.1:扔漂流瓶
使用 /扔漂流瓶 扔出漂流瓶 

如果扔出去的漂流瓶不能包含恐吓，色情，威胁等内容
如果因此导致对应的qq bot账号被封禁你将会受到严厉的惩罚
我们也会定期检查漂流瓶里面的内容(已经打开的) 如果查出发送此类内容 立刻剥夺bot使用权

2.2:捡漂流瓶
使用 /捡漂流瓶 捡起漂流瓶(如果没有漂流瓶则捡不了)

3:使用规范
不允许发送大量内容给bot(太烧token了)
